# EarnCheck release status

**27 September 2026**

EarnCheck is an original, AI-assisted local demo. Its three examples are synthetic and clearly labelled. Example mode runs without an account or API key and makes no SERV request.

The SERV chat-completions integration is implemented and covered by mocked HTTP tests. A real SERV account/key call has **not** been completed or verified, so this release does not claim a live SERV result or hackathon eligibility. The interface is not deployed publicly.

The final local test run on 27 September 2026 passed **19 of 19** Node tests. Tests cover source-quote validation, reward and fee distinctions, exhausted awards, unknown payout timing, unsafe HTML rendered as text, local request limits, Host/Origin restrictions, and the mocked SERV path.

The included screenshots show a synthetic example, not a real earning opportunity or a live model response. No earnings are claimed.
